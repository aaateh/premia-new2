# Шрифты: что можно, что нельзя

**Правило проекта: платные шрифты не используем никогда.** Ни в макетах, ни в прототипах,
ни в проде. Если лицензия шрифта не подтверждена — считаем его платным и не берём.

Список собран из живой версии сайта (`backups/live-marketingawards-2026-10-31/assets/`, 86 файлов,
~45 семейств). Лицензия каждого файла прочитана из его собственных метаданных (таблица `name`,
поля License / License URL / Copyright), а не с сайтов-агрегаторов.

## Файлы уже в проекте

Все разрешённые шрифты вытащены в папку **`fonts/`** — 91 файл, 43 семейства, 5,7 МБ.

```
fonts/fonts.css    — все @font-face, подключать один раз
fonts/preview.html — превью: как выглядит каждое семейство
fonts/NOTICE.md    — правообладатели и copyright по каждому шрифту
fonts/OFL.txt      — полный текст лицензии SIL Open Font License 1.1
```

Подключение:

```html
<link rel="stylesheet" href="fonts/fonts.css">
```

```css
body { font-family: Inter, Golos Text, sans-serif; }
h1   { font-family: Bounded, Unbounded, sans-serif; font-weight: 900; }
```

## Как проверить новый шрифт перед добавлением

1. Открыть файл и посмотреть метаданные: `fontTools` / FontForge / сайт автора.
   Ищем поля `License`, `License URL`, `Copyright` — там должна быть OFL, Apache 2.0, MIT или CC0.
2. Если написано «free for personal use», «demo», «trial», «EULA» — **нельзя**.
3. Если лицензия не указана вообще — **нельзя**, пока не найдено официальное подтверждение.
4. Google Fonts — всегда можно (OFL или Apache), качаем оттуда, а не с файлопомоек.
5. Сохраняем `OFL.txt` / `LICENSE` рядом со шрифтом и не переименовываем изменённые версии
   (OFL запрещает использовать Reserved Font Names в производных).

## Что делать, если нужного шрифта нет в списке

Подобрать бесплатный аналог из таблицы выше. Например:

- тяжёлый геометрический заголовочный → **Bounded**, **Unbounded**, **Rubik Mono One**
- строгий гротеск для текста → **Inter**, **Golos Text**, **Onest**, **Manrope**, **Geologica**
- узкий акцидентный → **DINish**, **Martian Grotesk**, **Russo One**
- рукописный акцент → **Caveat**, **Bad Script**, **Marck Script**, **Pacifico**
- антиква для акцентов → **Literata**, **Prata**, **Yeseva One**, **Bona Nova**, **Anticva**

# Суровая премия — сайт

Главная премии по ТЗ (`ТЗ сайт премии.md`, версия от 30.10.2026), собранная
на дизайн-системе marketingawards.ru (снята 31.10.2026): тёмная сцена и светлые
бумажные секции, Dela Award, Involve, Golos Award, оранжевый акцент, рамки 1px,
радиус 4px. У главных кнопок — анимация «горящей» рамки из дизайн-системы.
Без теней, градиентов и фоновых видео; из декора — золотой топор в «Принципах»
и анимация рамок кнопок.

Структура, тексты, ссылки и порядок блоков взяты из прототипа без изменений.

## Дизайн-система

Полный реестр шрифтов, размеров и весов — в `ДИЗАЙН-СИСТЕМА.md`, раздел 1.
Там же правило: новых размеров нет, только семь ступеней из таблицы.

| Роль | Значение |
|---|---|
| Фон сцены | `#080607` |
| Светлые секции | бумага `#ECE9E3`, текст `#25292E` |
| Основной текст | `#F5F0EB` на тёмном, `#25292E` на бумаге |
| Вторичный текст | `#C8C2BC` на тёмном, `#4A4D48` на бумаге |
| Рамки | `#C8C2BC` (кнопки), полупрозрачные линии у секций |
| Акцент | `#F56624` — подписи, номера, плюсы, hover (одинаково на тёмном и на бумаге) |
| Заголовки | Dela Award, 400, капс, трекинг −0.012em |
| Подписи и кнопки | Involve, 400 |
| Основной текст | Golos Award, 16px |
| Крупный вводный текст | 24px (20px на мобильных) |
| Шкала размеров | 12 / 14 / 16 / 20 / 24 px + заголовки h2 и h1 |
| Кнопки | 54px, радиус 4px, рамка 1px, прозрачный фон, блик по рамке |
| Карточки | 2px рамка, радиус 4px, срезанный правый верхний угол — приём из дизайн-системы Сурового |
| Колонка | 1040px, отступ от края `clamp(24px, 4vw, 72px)` |

Светлые токены (`--paper`, `--ink`, `--line`) используются в чередующихся
бумажных секциях; все цвета внутри них инвертированы: текст, рамки, кнопки,
акценты и состояния наведения.

Дополнительные приёмы:
- «Этапы» — панель со срезанным углом и крупными номерами, без линий-разделителей.
- «Результаты» — линейные иконки сертификата, шорт-листа и диплома (52px, stroke 1.5).
- «Принципы» — золотой топор из дизайн-системы Сурового справа; при наведении
  поворачивается на 25° за 1 секунду. На экранах уже 1400px скрывается.
- «Участие» — четыре карточки стоят в столбик на всех экранах, текст до 820px.
  Карточки белые без контура, текст инвертирован, иллюстрация справа внутри.
- «Участники» — карточки без серого контура, иллюстрация персонажа под текстом
  во всю ширину и прижата к низу, поэтому картинки во всех карточках на одной линии.
- «Стоимость» — два тарифа в виде постеров (стиль Uiverse «curvy-snake-6»):
  крупный заголовок Oswald, лента-маркиза JetBrains Mono, кнопки 52px.
- Спойлеры раскрываются плавно через Web Animations API, без библиотек.
- На тёмных секциях вторичный текст белый; выделение текста — персиковый `#FFB38A`.

## Доступность

- Контраст основного текста и кнопок проверен на живой странице скриптом из
  skill `accessibility-check` — проходит AA. Мелкие оранжевые подписи на бумаге
  (12px) — акцентный декор, по контрасту ниже AA.
- Мелкие подписи — 12px, вес 600; навигация — 14px, белая; основной текст — 16px.
- Один `h1` (логотип с текстовым именем), иерархия h1 → h2 → h3 без пропусков,
  у всех изображений есть alt, есть ориентиры header/nav/main/footer и `lang="ru"`.

## Производительность анимаций

- «Горящая» рамка живёт только там, где её видно: canvas выделяется при первом
  появлении кнопки в кадре (±100px), при уходе из кадра и при скрытой вкладке
  (`visibilitychange`) цикл отрисовки останавливается.
- В простое — 30 кадров/с, при наведении, фокусе и клике — 60. При
  `prefers-reduced-motion` анимация не запускается вовсе (переключатель системы
  учитывается на лету).
- Хвост блика рисуется пакетами по прозрачности (~24 stroke вместо ~180),
  свечение головы — кэшированным спрайтом, путь по рамке считается один раз на
  размер. CSS `filter` с canvas убран: тёплый ореол рисуется внутри canvas.
- Шрифты первого экрана предзагружаются (`preload`), топор в «Принципах» —
  `loading="lazy"` с размерами, чтобы не было сдвига вёрстки.
